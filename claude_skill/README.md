# mindtask Claude Code skill

`SKILL.md` teaches Claude Code how to use the mindtask CLI via natural language.

## Installation

Copy `SKILL.md` to one of these locations:

**Project-level** (applies to one repo):
```
.claude/skills/mindtask/SKILL.md
```

**Personal/global** (applies everywhere):
```
~/.claude/skills/mindtask/SKILL.md
```

## Keeping in sync

The skill file documents CLI behavior for a specific mindtask version. When you upgrade mindtask, copy the matching `SKILL.md` from the release.
